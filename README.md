Entrants write the funniest one line a talking elevator could say, 120 characters at most. A judge model compares lines in pairs and the funniest takes the $2 reward.

## The line

> Floor 13. We don't have a floor 13. I just wanted to see your face.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to
write somewhere else for a local test). The gate requires UTF-8 text of
1 to 120 characters, not only white space — this line is 67 characters.
